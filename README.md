# LINK-TO-QR
Alat untuk membuat link menjadi kode qr, dan memindai kode qr menjadi link. hanya dengan menggunakan bahasa program python, tanpa perlu mencari website atau aplikasi yang dapat mengubah link menjadi qr, atau memindai qr jadi link.
saya bias membuat tools yang bagus untuk membantu anda, membuat qr atau memindai qr, tanpa harus pergi ke website, atau mendownloads aplikasi.
anda hanya cukup install termux, atau terminal apapun yang sekiranya dapat mengistal tools saya, dan anda hanya perlu sedikit mengatur tools saya, agar dapat di gunakan tanpa memikirkan penyimpanan perangkat anda, atau pun link phishing website berbahaya.
